Mis Proyectos

E-commerce

E-commerce

Desarrollé una plataforma de comercio electrónico integral, desde el inicio de sesión del usuario con almacenamiento seguro de información hasta el control total del negocio. Implementé el flujo completo de ventas con catálogo dinámico, carrito de compras, gestión de pedidos y un panel administrativo (CRUD) para el control de inventario. Incluí sistema de autenticación por tokens, cifrado de contraseñas mediante hashing, sanitización de datos y guardado seguro de información en base de datos, todo alineado con estándares ISO de seguridad. Automatice la comunicación con envíos masivos de correos electrónicos mediante la API de Resend. La plataforma fue construida con PHP, MySQL, JavaScript y Bootstrap. Como entrega final, elaboré manuales técnicos y de usuario detallados, junto con el diagrama completo del sistema, asegurando su mantenimiento y escalabilidad.
Consulta de Información

Consulta e Inteligencia de Datos

Desarrollé una plataforma web que integra información en tiempo real mediante la API de Google Cloud y APIs especializadas para el procesamiento automático de informes. Incluye una sub-versión para WordPress y arquitectura de bases de datos interconectadas.

Implementé un sistema con más de 9 capas de seguridad, una de las capas contiene: encriptación de info crítica, hashing de datos sensibles, 2FA interno, integridad constante y cierre de sesión automático. El resto de las capas se mantienen bajo reserva técnica.

Incluye automatización total de usuarios y se hizo entrega de 3 manuales completos (técnico, usuario y administración) con toda la documentación del sistema.
